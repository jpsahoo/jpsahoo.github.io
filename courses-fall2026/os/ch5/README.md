# CPU Scheduling — Lecture Notes (IC3012301, Fall 2026)

Files (keep them in the **same folder**): `index.html`, `style.css`, `app.js`, `data.js`, `.nojekyll`.
All teaching text and example data live in `data.js`; `data.json` is no longer used (delete the old copy).

## Run locally
Just double-click `index.html` (works from `file://`, no server needed).
Bootstrap and MathJax load from the jsDelivr CDN, so you need an internet connection.
Optional local server: `python -m http.server` → http://localhost:8000

## Publish on GitHub Pages
1. Create a repository and upload the files above (to the repository root).
2. Settings → Pages → Source: *Deploy from a branch* → branch `main`, folder `/ (root)` → Save.
3. Open `https://<your-user>.github.io/<repo>/` after about a minute.
File names are case-sensitive on GitHub Pages — do not rename them.
